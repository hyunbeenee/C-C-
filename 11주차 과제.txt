1. 구조체 포인터로 멤버에 접근할 때 사용하는 연산자는?
1: . | 2: & | 3: -> | 4: *		정답 : 3: ->

2. 다음 코드의 출력 결과는? 
struct Num { int age; };
void grow(struct Num* d){
    d->age = 5;
}
int main(){
    struct Num d1 = {2};
    grow(&d1);
    printf("%d", d1.age);
}
1: 2 | 2: 5 | 3: 0 | 4: 에러		정답 : 2: 5

5. 다음 코드의 출력 결과는?
enum Season { Spring, Summer, Fall, Winter };
enum Season s = Summer;
switch (s){
    case Spring: printf("Warm\n"); break;
    case Summer: printf("Hot\n"); break;
    case Fall:   printf("Cool\n"); break;
    case Winter: printf("Cold\n"); break;
    default: printf("Unknown\n"); break;
}
1: Cold | 2: Hot 3: | Cool | 4: Unknown	정답 : 2: Hot
